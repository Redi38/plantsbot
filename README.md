# Plant Bot 🌿

Telegram-бот для учёта комнатных растений: группы, импорт списков (в т.ч. из GPT), добавление/удаление, свободный ИИ-агент.

## Структура

```
bot/
├── config.py
├── main.py
├── db/
│   ├── models.py      # User, Group, Plant
│   ├── database.py    # engine/session (SQLite + WAL)
│   └── crud.py
├── services/
│   ├── plant_service.py
│   ├── group_service.py
│   ├── import_service.py   # CSV + markdown парсеры, предпросмотр импорта
│   └── ai_service.py       # намерения из свободного текста
├── handlers/
│   ├── list_view.py    # /start, /help, /list
│   ├── plants.py       # /add, /delete (FSM)
│   ├── groups.py       # /rename_group (FSM)
│   ├── import_.py      # /import — файл или текст, предпросмотр, подтверждение
│   └── ai_agent.py      # свободный текст → intent → действие
└── keyboards/
    └── inline.py

admin/                    # веб-админка (FastAPI), деплоится отдельным контейнером рядом с ботом
├── main.py                # роуты
├── database.py             # своё подключение к той же БД (без зависимости от bot.config)
├── auth.py                 # HTTP Basic Auth
├── requirements.txt
├── Dockerfile
└── templates/
```

## Запуск локально

```bash
cd plant_bot
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# впиши BOT_TOKEN (обязательно) и AI_API_KEY (если хочешь ИИ-агента)

python -m bot.main
```

## Запуск в Docker

```bash
cp .env.example .env
# заполни .env

docker compose up -d --build
```

SQLite-файл живёт в именованном volume `plant_bot_data`, так что данные переживут пересборку контейнера. `docker compose up` поднимает два контейнера — `bot` и `admin` — которые используют один и тот же volume.

## Веб-админка

Отдельный сервис `admin` (FastAPI + Jinja2, без JS-фреймворков) для быстрого редактирования данных мышкой, если не хочется делать это через Telegram. Работает поверх тех же таблиц (`bot.db.models`, `bot.db.crud`) — единый источник схемы, никакого дублирования БД.

Возможности: список пользователей бота → для каждого — группы и растения, добавление/удаление/переименование групп, добавление/удаление/редактирование (имя, комментарий, перенос в другую группу) растений.

Защищена HTTP Basic Auth (`ADMIN_USER` / `ADMIN_PASSWORD` в `.env` — обязательно смени значение по умолчанию).

По умолчанию порт админки пробрасывается только на `127.0.0.1:8080` на самом сервере — снаружи не виден. Открыть доступ можно одним из способов:
- SSH-туннель: `ssh -L 8080:localhost:8080 user@oracle-instance` и открыть `http://localhost:8080` у себя
- поставить nginx/caddy с HTTPS перед портом 8080 (раз это открытая в интернет форма для удаления данных — лучше не открывать голый HTTP наружу)

Если решишь открыть порт напрямую в интернет (не рекомендуется без HTTPS), поменяй в `docker-compose.yml` `127.0.0.1:8080:8080` на `8080:8080`.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start`, `/help` | список команд |
| `/list` | общий список всех растений по группам (дерево) |
| `/add` | добавить растение — название → группа → комментарий |
| `/delete` | удалить растение (со списком и подтверждением) |
| `/rename_group` | переименовать группу |
| `/import` | импорт списка из CSV-файла или текста |
| `/cancel_import` | отменить активный /import |

## Формат импорта

**CSV** (с заголовком):
```csv
group,name,comment
Алоказии,Алоказия Полли,пересадила в марте
Алоказии,Алоказия Одора,
Суккуленты,Хавортия,
```

**Текст / markdown:**
```
Алоказии:
- Алоказия Полли: пересадила в марте
- Алоказия Одора

Суккуленты:
- Хавортия
```

В обоих случаях перед сохранением бот показывает предпросмотр: какие группы новые, какие смэтчились с существующими (сравнение регистронезависимое, с обрезкой пробелов) — и просит подтверждения.

## ИИ-агент

Если `AI_ENABLED=true` и указан `AI_API_KEY`, любое сообщение вне активных команд/сценариев прогоняется через `ai_service.parse_intent()` — работает с любым OpenAI-совместимым API (OpenAI, DeepSeek, OpenRouter и т.д., просто поменяй `AI_API_BASE_URL` и `AI_MODEL` в `.env`).

Примеры:
- «добавь алоказию полли, пересадила в марте» → добавит в группу «Алоказии» с комментарием
- «удали хавортию» → удалит, если находится однозначно

## Что можно добавить дальше

- Мультиязычность (поле `User.language` уже заложено в модели)
